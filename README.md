# 🖼️ Image Slider Project

مشروع بسيط باستخدام JavaScript لعرض صور بشكل متحرك (Slider).

---

## 🚀 فكرة المشروع

عرض مجموعة صور مع إمكانية التنقل بينها:
- الصورة التالية ▶️
- الصورة السابقة ◀️
- عرض الصور بشكل متسلسل

---

## 🛠️ التقنيات المستخدمة

- HTML5
- CSS3
- JavaScript (DOM)

---

## ✨ المميزات

- التنقل بين الصور بسهولة
- التحكم في عرض الصور
- واجهة بسيطة وسريعة

---

## 🧠 المفاهيم المستخدمة

- Arrays
- DOM manipulation
- Event listeners (onclick)
- تغيير src للصورة ديناميكيًا

---

## 📂 هيكل المشروع
image-slider/
│── index.html
│── style.css
│── script.js
│── README.md



---

## ▶️ طريقة التشغيل

1. افتح ملف `index.html`
2. اضغط "التالي" أو "السابق"
3. شاهد الصور تتغير
